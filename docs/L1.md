## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
 
    -red bar พิสูจน์ว่า test ที่เราเขียนจับความผิดพลาดได้จริง เพราะมัน fail ตอนที่ยังไม่มีโค้ดที่ถูกต้อง
   ถ้าเห็นแต่ green bar เราแยกไม่ออกว่า test ผ่านเพราะโค้ดถูก หรือเพราะ test ไม่ได้ตรวจอะไรเลย
   ดังนั้นการเห็น red ก่อน green ทำให้มั่นใจว่า green bar ครั้งต่อมามีความหมาย

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน

    -กู้ได้จาก GitHub repository โดยต้อง git commit และ git push ไว้ก่อน เพราะงานที่ยังไม่ push จะหายไปพร้อมเครื่อง
   หลังจากนั้นก็ git clone repository มาที่เครื่องใหม่ แล้วรัน ./mvnw เพื่อให้ Maven ดาวน์โหลด dependency กลับมาเอง
   ควร commit และแบ่ง push เป็นช่วงๆ ไม่รอจนงานเสร็จทั้งหมด
